# Security

WirelessCanvas RGB runs with administrator rights (for the CPU sensor and OpenRGB RAM access), talks to USB devices and opens local TCP connections to OpenRGB on `127.0.0.1` only.

If you find a security problem, for example a way to make the app send unexpected commands to hardware or to run code with its rights, please do not open a public issue. Use GitHub's **Report a vulnerability** (private advisory) on this repository instead. You will get an answer as soon as possible; this is a hobby project without guaranteed response times.

Only the latest release gets fixes.
